## 2.1.0

- Добавлен английский язык. По умолчанию язык берётся из браузера, сменить его можно в Настройки → Язык.
- Название и описание расширения переведены (`_locales`).
- Папка-зеркало в закладках называется «Tablo» в английском интерфейсе; уже существующая папка «Табло» распознаётся и используется как раньше.
- Погода и поиск по картинке используют язык интерфейса.

## 2.0.2

- Интерфейс собирается через DOM, без присваивания `innerHTML` (убраны предупреждения валидатора AMO).
- Минимальная версия Firefox 140 (Android 142): с неё поддерживается `data_collection_permissions`.

## 2.0.1

- Виджеты по умолчанию в цвет темы; пастельные цвета остаются в переключателе.
- Убраны приветствие под датой и заливка плиток цветом иконки.
- Внутри открытой папки значки больше не размываются (размытие остаётся на плитке папки).
- Значок вкладки по умолчанию — эмодзи ❤️.
- У ползунков в настройках показываются числа.
- Кнопка «⋯» меняет цвет вместе с темой.

## 2.0.0

- Код переписан на ES-модули с понятной структурой.
- Блоки в режиме правки привязываются к сетке по своим краям, а не «мимо» неё.
- Тёмные элементы (поиск, быстрые ссылки, плитки, меню, панель настроек) включаются автоматически на тёмных темах; в настройках можно включить их всегда или выключить.
- Свободные места на сетке тёмные и неприметные, плитки выделяются сильнее; места подсвечиваются только при переносе.
- Панель настроек прозрачная, как фон, с тонкой обводкой; GitHub автора — значком.
- Из приветствия убрано имя.
- Аддоны (песочница с пользовательским кодом) удалены; из разрешений убран `unsafe-eval`.
- Новый идентификатор расширения `tablo-newtab@btwkek`. Перед переходом со старой версии сделайте экспорт настроек.
