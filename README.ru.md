# Своё табло (Tablo)

[English](README.md) · **Русский**

Новая вкладка для Firefox: часы, поиск, плитки сайтов, папки, быстрые ссылки и настраиваемый фон.

## Возможности

- Часы, дата и погода по выбранному городу.
- Поиск: адрес открывается напрямую, остальное уходит в выбранный поисковик (Google, DuckDuckGo, Bing или как в браузере).
- Плитки и папки с перетаскиванием; сайты можно взять из закладок.
- Темы, свой градиент или своя картинка на фон. Тёмные элементы (поиск, плитки, меню) включаются сами на тёмных темах, а также могут быть включены или выключены вручную.
- Режим правки: блоки страницы двигаются по сетке с привязкой.
- Виджеты: заметка, задачи, отсчёт до даты, таймер.
- Экспорт и импорт настроек в JSON.
- Интерфейс на русском и английском.

Язык интерфейса по умолчанию совпадает с языком браузера; его можно сменить в Настройки → Язык.

## Установка

Нужен **Firefox 140 или новее на компьютере**. Firefox для Android не позволяет расширениям подменять новую вкладку, поэтому там расширение не работает.

Скачайте подписанный файл `.xpi` со страницы [Releases](../../releases) и откройте его в Firefox.

## Разработка

```bash
npm install
npm start        # Firefox с расширением и автоперезагрузкой
npm run lint     # проверка манифеста и кода
npm run build    # архив в dist/
```

Сборки нет: Firefox загружает файлы из `src/` как есть. Структура папок описана в [README.md](README.md#development).

Подпись и публикация: [docs/PUBLISHING.md](docs/PUBLISHING.md).

## Конфиденциальность

Все данные хранятся локально в браузере. Наружу уходят только два вида запросов:

- **Значки сайтов:** домены ваших плиток и быстрых ссылок отправляются в сервис значков Google (`google.com/s2/favicons`).
- **Погода:** название города, который вы ввели, отправляется в Open-Meteo (`open-meteo.com`). Пока город не задан, запросов нет.

Доступ к закладкам запрашивается отдельно и только по вашему согласию. Аналитики и рекламы нет.
